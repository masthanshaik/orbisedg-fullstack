# Static design preview

Open `index.html` in a browser to see a static homepage preview. This preview is included only for quick visual review; the functional website is the Next.js application under `apps/web`.

The two PNG files are visual-direction references from the earlier Orbisedg/Nimo design pass. The new Next.js implementation uses the same dark, acid-lime, oversized-type direction, while its exact responsive rendering comes from `apps/web/app/globals.css`.
